# MiniEcommerce

## 📌 Project Statement

MiniEcommerce is a small e-commerce API project built with **Spring Boot**.

The project is designed to practice and strengthen backend development concepts such as REST APIs, database integration, JPA, DTOs, validation, entity relationships, and business logic.

## 🎯 Why I Am Building This

I am building this project as a **learning and practice project** to apply the Spring Boot concepts I have learned and gradually move beyond basic CRUD operations.

The goal is to understand how different backend components work together in a real-world-style application.

## 🚧 Current Status

**Currently under development**

This is a **mini project for learning and practice**, not a production-ready application.

More features and backend concepts will be added gradually as development continues.
